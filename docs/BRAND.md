# Бренд и UX-требования POKER HUB

> Список «как должно быть». При расхождении кода с этим списком — побеждает этот список.

>
> Ранее этот раздел жил в `CLAUDE.md §8.1.1`. Вынесен 2026-05-29 в рамках декомпозиции (см. `CLAUDE.md §8` ссылки).

## Бренд

- Название рума — **POKER HUB** (раньше было SK Poker, переименовано 2026-05-26 под домен `poker-hub.city`).
- Лого POKER HUB в navbar (на всех страницах) — CSS-класс `.neon-logo` в [client/src/index.css](../client/src/index.css): белый текст + циан/мадженто text-shadow glow, **без пульсации** (steady), letter-spacing 0.08em.
- `<title>` страницы — «Poker Hub» ([client/index.html](../client/index.html)).
- Большой неон-заголовок на MainMenu **не нужен** — в navbar достаточно. Класс `.neon-title` (с пульсацией) оставлен в CSS как fallback, не используется.

## MainMenu (`/`)

- Фон — картинка `/images/main-bg.jpg` на весь экран (`object-cover`), **без затемнения** (overlay убран).
- Кнопки Quick Play / Create Room / Tournaments на странице **убраны** — навигация только через nav-bar.
- На странице остаётся только статус-блок снизу (Online · v · Browser/Telegram badge).
- Турниры доступны как 4-я вкладка в bottom-bar и desktop-nav, **disabled с подписью «скоро»** (страницы ещё нет).

## Showdown UX (важно)

- Карты в выигрышной пятёрке (`winningCards` из `GAME_WINNER`) — **выдвигаются вверх** (`y: -18px`, slight `scale: 1.06`), **без свечения/рамки/пульсации**. Lift = единственный визуальный сигнал.
- Карты НЕ в выигрышной пятёрке (community вне комбо, hole-карты проигравших, не-играющие hole-карты победителя) — **приглушаются** (`opacity: 0.45`). Не убираются полностью — остаются читаемыми.
- Аватар победителя — золотое кольцо + glow (`ring-yellow-400`).
- **Никакой большой жёлтой плашки** «Победитель» по центру — удалена 2026-05-22.
- На showdown карты всех (включая проигравших) показываются face-up — нужно видеть кто что играл.
- **Эффект победы (как в GGPoker, 2026-06-07):** 5 карт победной комбинации — лифт вверх + пульсирующее золотое свечение (`.card-win-glow`) + лёгкое увеличение (~4%); все остальные карты (борд + проигравшие) уходят в тень (`.card-dim`: затемнение/десатурация + opacity). Реализация эффекта — в [Card.tsx](../client/src/components/game/Card.tsx) (`highlight`/`dim` применяются во ВСЕХ ветках рендера, в т.ч. картиночной колоды — раньше там игнорировались). Победитель подписан: **WIN + сумма** (бейдж над картами) и **имя комбинации** (плашка под игроком) — `PlayerSeat`/`MobilePlayerSeat`. Сумму шлёт сервер в `gameWinner.amounts` (per-winner, учитывает side-pots), имя — `gameWinner.handName`.

## Admin-peek («глазик» в админ-UI, mobile)

- Карты соперников показываются маленькими — `size="sm"` (как рубашки), не lg.
- **Мои карты не дублируются** — overlay для self скрывается, я и так вижу свои в bottom-блоке.
- Будущие community-карты (которые ещё выйдут на flop/turn/river) — рисуются полупрозрачно с красной обводкой рядом с уже открытыми.
- Peek-флаг **не сохраняется** при reconnect/refresh — безопасный дефолт (по умолчанию выключен).

## Временный кик игрока со стола (2026-06-05)

- Админ может выгнать игрока со стола **без бана** аккаунта (игрок остаётся залогинен, может сесть за другой стол). Кнопка «Кикнуть» в [RoomsTab](../client/src/pages/admin/RoomsTab.tsx) спрашивает кулдаун в минутах (ввод вручную, 0 = без блокировки, макс 1440).
- Кулдаун — **per-стол** (`room.kickCooldowns: Map<userId, expiresAt>`), хранится в памяти. Повторный вход за этот стол до истечения → отказ `on-cooldown` с остатком времени («Попробуйте через N мин»). По истечении — снимается (ленивая очистка в `canJoinRoom` + таймер). Реализация — серверная (`adminKickPlayer(roomId, userId, cooldownMin)` + `canJoinRoom`), клиентский `isAdmin` ничего не решает (§0.12).

## Очередь на полный стол (waitlist, 2026-06-05)

- На **полном** столе в лобби вместо заблокированной кнопки — «Занять очередь» (янтарная). Любой игрок может встать в очередь; бай-ин выбирается сразу (та же модалка, что при обычной посадке) и спишется при авто-посадке.
- Когда место освобождается (выход/кик/сит-аут-таймаут), через **задержку стола** `waitlistDelayMin` (per-table, 2..10 мин, дефолт 2, слайдер при создании) первого валидного из очереди **автоматически сажают** (событие `seatFromWaitlist` → клиент переходит за стол; слушается глобально в [Layout](../client/src/components/layout/Layout.tsx)).
- Очередь — FIFO, в памяти (не персистится). Невалидных на момент посадки (офлайн / не хватает банкролла) — пропускают, садят следующего. Игрок видит свою позицию на карточке («В очереди: N-й») и может выйти.
- **Резервирование:** пока очередь непуста, освободившееся место зарезервировано за ней — прямой вход (`canJoinRoom`) возвращает 'full', прохожие из лобби тоже встают в очередь (стол показывается «полным» при `waitlistIds.length>0`). Иначе очередь была бы бессмысленна — место перехватил бы любой за время задержки.
- События: `joinWaitlist`/`leaveWaitlist`/`seatFromWaitlist` (в `SOCKET_EVENTS`). Позиция/счётчик — через `RoomInfo.waitlistIds` в обычном `roomList` (клиент находит свой индекс, как с `playerIds`). Серверная логика — `joinWaitlist`/`promoteFromWaitlist` в [GameManager](../server/src/game/GameManager.ts), триггер в `removePlayer`.

## Меню стола снизу (mobile/TWA, 2026-06-11)

- На mobile/TWA верхний бар стола **спрятан** — его кнопки (баланс, админ-вход, Инфо, peek-глаз, реакции, настройки, Выход) уехали в нижнее **выезжающее меню** [MobileTableMenu.tsx](../client/src/components/game/MobileTableMenu.tsx). Чистый стол без верхнего оверлея.
- Вызов: **свайп снизу-вверх** по ручке или тап по ней. Скрытие: свайп вниз по «грипу», тап по затемнению или выбор действия. Анимация — `translateY` (transform, §0.10), не layout-свойства.
- Ручка-намёк видна внизу-по-центру, **кроме своего хода** (`hideHandle={isMyTurn}`) — чтобы не перекрывать кнопки ActionPanel. Открытая панель идёт поверх стола (z-50 + backdrop z-40).
- На **desktop** верхний бар остаётся как был (`hidden md:flex` в [GameRoom.tsx](../client/src/pages/GameRoom.tsx)); баланс/админ — в Layout navbar.

## История раздач (MVP, 2026-06-12)

- Иконка **истории** (`History`, top-right): на mobile отдельная кнопка в углу стола, на desktop — в верхнем баре. Открывает [HandHistoryModal](../client/src/components/game/HandHistoryModal.tsx).
- Модалка: список последних раздач (время · мои карты · блайнды · мой net зелёным/красным) → тап → деталь (борд, строки игроков с их картами/folded/net, победитель + сумма, имя комбинации, банк).
- Данные с `GET /api/hands` ([hands.routes.ts](../server/src/routes/hands.routes.ts)); снимок раздачи пишет сервер в `hands-detailed.json` ([handHistory.ts](../server/src/game/handHistory.ts)). **Приватность §0.1:** чужие карманные показываем только для рук, дошедших до showdown (иначе — рубашки).
- **Ход раздачи (replay):** в детали — раздел «Ход раздачи» по улицам (Префлоп/Флоп/Тёрн/Ривер) с бордом улицы и списком действий (блайнды/анте + ходы). Данные из `actions` снимка (per-action лог на сервере).
- **Осталось:** визуальный анимированный stepper, админ-доступ ко всем рукам. См. [ROADMAP §10.10](ROADMAP.md).

## Мультитейблинг — пилюли столов (2026-06-12)

- До **3 открытых столов** одновременно на одном сокете (несколько socket.io-комнат, §0.6 не нарушаем — сокет один). Эталон — ClubGG-скрин: top-left пилюли + «+».
- Пилюли ([TablePills.tsx](../client/src/components/game/TablePills.tsx)) в левом-верхнем углу стола: каждая показывает **мои карты** (мини), активный стол — emerald-обводка, стол где **подошёл мой ход** — янтарная пульсация. Клик по пилюле — переключение активного стола (navigate). «+» открывает лобби для нового стола (прячется на 3).
- Состояние всех открытых столов держит глобальный [tablesStore](../client/src/store/tablesStore.ts), наполняется персистентным [TablesManager](../client/src/components/game/TablesManager.tsx) (в [Layout](../client/src/components/layout/Layout.tsx), переживает навигацию) из `gameUpdate` (маршрутизация по `roomId`). Активный стол по-прежнему рендерит GameRoom через useGameRoom (фильтр по `roomId`, чтобы фоновый стол не перетирал вид).
- Сервер: посадка за несколько столов уже работает (`joinRoom` без guard'а на «другой стол»); лимит 3 — `too-many-tables` в [GameManager.canJoinRoom](../server/src/game/GameManager.ts); `roomId` добавлен в `GAME_WINNER`/`START_COUNTDOWN` (иначе showdown/отсчёт фонового стола мигал на активном).
- **Ограничение**: пилюли — session-scoped (store в памяти). Полный reload (F5) может сбросить фоновые столы (плюс disconnect-grace убирает игрока со столов). Восстановление открытых столов после reload — отдельная задача.

## Фишки (SVG, 2026-06-07)

- Векторные фишки сгенерированы скриптом [generate-chips.mjs](../scripts/generate-chips.mjs) (как колода) → [client/public/chips/](../client/public/chips/) `chip-{green,red,blue,purple,orange,gray}.svg`. Стиль один-в-один по референсу (одобрено пользователем): 8 белых вырезов-окон по ранту, пунктирное кольцо, 3D-толщина (тёмный боковой рант + тень), **пустой центр под номинал**. Уникальные id градиентов на цвет (иначе инлайн-коллизия → «зелёный ободок у всех»).
- **Номинал НЕ зашит** в картинку — рисуется в игре динамически по центру ([Chip.tsx](../client/src/components/game/Chip.tsx)), набор номиналов зависит от типа стола (микро / целочисленный). Сверка с референсом — `scripts/preview-chips.html` (рендер через `/browse`, скриншот → агент-сверщик). Источник-референс был вотермаркеным стоком — НЕ использовали, нарисовали вектор.
- **Фиксированная лестница номиналов** ([chipDenoms.ts](../client/src/config/chipDenoms.ts)) — как реальный набор казино, чтобы собрать ЛЮБОЙ банк точно. **11 цветов = 11 номиналов**, младший = **1 цент** (мин. единица денег) → любая сумма представляется без остатка: `0.01 white, 0.05 pink, 0.25 cyan, 1 blue, 5 red, 25 green, 100 black, 500 purple, 1000 orange, 5000 gold(жёлтый), 25000 brown`. Светлые (white/gold) — тёмная подпись; white — синие вырезы (`CHIP_TEXT_DARK`). orange/gold разведены по тону (оранжевый vs жёлтый), чтобы 1000/5000 не сливались.
- **Подпись номинала** (`denomLabel`): центы — десятичные `0.01/0.05/0.25` (по выбору пользователя — так понятнее), доллары — числом `1/5/25/100/500`, тысячи — `1K/5K/25K`. Вылезание за фишку решено НЕ сменой формата, а **ужатием кегля под длину строки** в [Chip.tsx](../client/src/components/game/Chip.tsx) (4 символа «0.01» — мельче). Вариант с `¢` рассматривали, но пользователь предпочёл нули.
- **Разбивка банка на стопки по номиналам** ([ChipStack.tsx](../client/src/components/game/ChipStack.tsx)): `breakIntoChipGroups(amount)` (жадно, от крупных) → набор стопок (крупные слева), как фишки на реальном столе, + точная сумма подписью. Видимая высота стопки одного номинала ограничена (VIS_CAP=6) — сумма в подписи всегда точная. Старая тема `chipStyle` для ставок не влияет (цвет = номинал). Почему так: чтобы отобразить любой стейк/банк нужен набор от мин. единицы по ×5-лестнице (~9–11 номиналов), см. ресёрч в истории чата. Превью: `scripts/preview-chips.html` (палитра), `scripts/preview-chips-bets.html` (разбивка).

## Telegram MiniApp

Deep-link базы — [lib/telegram.ts](../client/src/lib/telegram.ts).

## Админка — список игроков и детали (эталон 2026-06-05)

**Список** ([PlayersTab.tsx](../client/src/pages/admin/PlayersTab.tsx)): тёмные карточки, аватар-квадрат (`rounded-xl`) + флаг-бейдж в углу, ник (`font-semibold text-[15px]`) + `ID : XXXX-XXXX`, короткий вертикальный разделитель, справа красная фишка-маркер + баланс; нижняя инсет-строка «Псевдоним <alias>» (`bg-black/30`). ## Деньги (валюта) — центы (2026-06-05)

- **Единица — цент.** Все денежные величины (баланс/chips, блайнды, банк, ставки, стеки, бай-ин-суммы, анте, рейк, PnL) внутри — **целые центы**. Математика покера остаётся целочисленной → расчёты точны до цента, без float-ошибок. Сервер НЕ меняли (он уже целочисленный — просто единица теперь «цент»).
- **Отображение — дробное, без знака валюты** (как в эталоне): `1` → `0.01`, `2080874` → `20,808.74`; целые суммы — без «.00» (`1000` → `10`, не `10.00`, сделано 2026-07-03 — нули не несут информации, только шум за столом). Через `formatMoney(cents)` из [chipFormat.ts](../client/src/config/chipFormat.ts). Ввод сумм — через `parseMoney(dollarsStr)` (доллары → центы), блайнд-инпуты `step="0.01"`.
- **Правило для нового кода:** деньги НЕ выводить сырыми (`{chips}`, `{smallBlind}`) — только `formatMoney(...)`; на столе — `formatChips(...)` (учитывает режим chips/ББ). Поля в больших блайндах (`buyInMinBb`/`buyInMaxBb`/`rakeCapBb`) — НЕ деньги, не форматировать.
- **Микро-блайнды = от 1 цента** (`0.01/0.02`). Пресеты: Микро 0.01/0.02, Низкие 0.05/0.10, Средние 0.25/0.50, Высокие 1.00/2.00.
- Существующие балансы трактуются как центы (1000 → `$10.00`), без миграции.
