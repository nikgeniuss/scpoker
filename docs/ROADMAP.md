    Проценты — доля **пула** джекпота; остаток (≈ до 100%) переносится как seed следующего.

  **Триггеры (мин. квалифицирующая проигравшая рука), пресеты per-format:** NLH дефолт **AAAJJ или старше** (пресеты: AAA22 / AAA88 / **AAAJJ(деф)** / AAAKK / 2222 / 6666 …); Short Deck дефолт **AAAA или старше**.

  **Прежние уточнения (в силе):** один общий пул на столы с **открытым доступом**; **исключить** приватные столы и столы с **ботами**. Порядок отчисления при выплате банка: сначала рейк, потом дроп бэд-бита.

  **⚠️ Отличия под наш проект (memory game-formats: только NLH + Шорт-дэк):**
    - Карточки форматов — **только NLH + Short Deck**. PLO/PLO5 (на эталоне KKKK / 87654-suited) **убрать**, из текста правил убрать упоминания PLO/PLO-5.

    - **RIMT / «многократный вход»** — нет MTT, правило N/A.
